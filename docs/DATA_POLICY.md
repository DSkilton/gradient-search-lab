# Data use, provenance and reproducibility

- **Never commit:** passwords, access tokens, personal data, proprietary datasets, raw bulk imagery, large model artefacts or unknown-licence data.
- **For each source:** record provider, URL, terms, licence, date fetched, version, checksum, transformations and constraints.
- **For each experiment:** record code revision, data snapshot, splits, environment, seeds, parameters, metrics and total wall time.
- **For results:** distinguish simulation, toy examples, historical retrospective validation and any real-world operational capability.
- **Source uncertainty:** missing metadata is unknown, not reliable by default.

The starter is a one-dimensional convex toy search, not neural-network training; its result cannot establish a training speedup.
